Se contrastaron los repositorios `iperc-antapaccay-api` e `iperc-antapaccay-web` mediante lectura de dependencias, rutas, modelos, servicios, permisos y componentes conectados. Los documentos de planificación se trataron como contexto, no como prueba de implementación ni como instrucciones para cambiar el portafolio. No se copiaron reglas, dependencias o código de negocio al sitio.

## Capturas de la interfaz

La selección utiliza el módulo real de control de tareas, ejecutado desde una copia temporal aislada del frontend. Las respuestas de API se interceptan con datos sintéticos basados en sus fixtures de pruebas; no son registros persistidos ni consultas al backend real. La sesión es sintética y el destino backend apunta a un puerto local descartado. Se bloquea la red externa y se excluyen `.env`, `.git` y builds del origen de la copia. No se modifican los repositorios fuente ni se utiliza producción.

Tres PNG **1920×1080 (16:9)**, con viewport fijo y `fullPage: false`:

1. Tableros de control — portada.
2. Detalle de tareas y matriz de riesgos.
3. Consulta de reportes.

Los originales viven en `public/images/projects/iperc-antapaccay/`, con títulos, alternativas y captions ES/EN en `data/iperc-gallery.ts`. El [manifiesto de captura](previews/iperc-captures.json) registra dimensiones, huellas y contexto. El aviso de portada, galería y visor identifica **datos sintéticos y respuestas de API simuladas**. Las cifras no se presentan como usuarios, productividad o resultados operativos. Las capturas no demuestran persistencia, integración API, descarga real de documentos ni funcionamiento móvil.

## Límites editoriales y técnicos

- No se publica año, cargo, contrato, métricas de impacto, demo pública ni URL de repositorio. El nombre del proyecto no acredita una relación contractual o uso productivo.
- Los cuatro dashboards del frontend usan `DASHBOARD_MOCK = true` (`src/features/dashboard/config.ts:5`). Se excluyen de la galería y de las afirmaciones de seguimiento con datos reales.
- La API incluye observación y resolución, pero los modales web correspondientes no están montados en `IpercDetailView`. No se presentan como acciones web disponibles.
- La API contiene contratos de sincronización móvil. No se revisó ni ejecutó el código de la app móvil, ni se acreditan funcionamiento sin conexión, ausencia de pérdida de datos o aceptación integral.
- Se inspeccionaron capacidades en código, sin ejecutar la suite backend, infraestructura, notificaciones, exportadores ni servicios externos. La revisión no certifica cumplimiento normativo, seguridad integral o validez legal de firmas.
- Los timestamps del dispositivo tienen validaciones de tolerancia; no se describen como prueba criptográfica de autoría. Los snapshots y referencias de firmas no se presentan como documentos inmutables.
- La autoría declarada por el propietario se limita a API y panel web; la app móvil se atribuye a otros integrantes en ES/EN.

La verificación de rutas, traducciones, galería y adaptación del portafolio se registra por separado en [verification.md](verification.md).
