## Pendientes del propietario

El usuario indicó que completará sus datos al finalizar. El stack del perfil ya está confirmado en frontend, backend, base de datos y AWS básico para despliegue (ver content.md). Siguen pendientes la revisión editorial, la trayectoria laboral y nuevos casos de estudio autorizados; no hay tecnologías de IA confirmadas. Los campos pendientes no bloquean la base y no se sustituyen por datos ficticios.

El usuario posteriormente autorizó su caso full stack y capturas demo, ahora presentados sin código interno ni resultados comerciales inferidos. No se heredan su autenticación, backend, reglas de negocio ni dependencias al portafolio. La autorización de otros proyectos sigue siendo específica. No hay cifras de impacto ni historial laboral inferidos.

Auth, CMS, API, base de datos, envío de correo, analítica, blog, Three.js, hosting y dominio. Cualquier incorporación posterior debe justificar sus dependencias y verificarla.

No se crearon commits ni un remoto: el usuario solicitó el proyecto local. El requisito de commits por etapa del AGENTS de gm-social-web corresponde a ese otro repositorio y no se trasladó a este.
